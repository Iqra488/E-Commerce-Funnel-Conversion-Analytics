# Funnel Analysis

An end-to-end funnel analysis project focused on understanding customer journeys, identifying drop-off points, analyzing conversion performance, and finding revenue opportunities.

## Key Findings

* **Biggest Drop-off:** Purchase stage — **70.95%**
* **Best Channel:** Google Ads — **10.63% conversion**
* **Best Region:** South — **10.54% conversion**
* **Best Category:** Electronics — **11.16% conversion**
* **Best Device:** Desktop
* **Cart Abandonment:** **50.27%**
* **Potential Revenue Recovery:** **$954,906.62**

##  Recommendations

* Improve the UX and checkout process to reduce Purchase-stage drop-off.
* Further evaluate and optimize Google Ads performance.
* Analyze successful strategies from the South region.
* Promote high-performing Electronics products.
* Implement cart abandonment recovery strategies.
* Improve **mobile and tablet UI/UX**, as Desktop currently shows better funnel performance.
